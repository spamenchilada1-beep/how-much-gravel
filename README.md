# How Much Gravel Do I Need?

A small, accessible React/Vite gravel calculator that estimates cubic yards, tons, and a practical order quantity with transparent planning assumptions.

## Local development

```sh
npm install
npm run dev
```

Run checks with `npm test` and create the production output with `npm run build`.

## Cloudflare Pages

Use the React (Vite) preset, or set the build command to `npm run build` and the build output directory to `dist`.

Before production deployment, replace `https://example.com/gravel-calculator` in `index.html`, `public/robots.txt`, and `public/sitemap.xml` with the final canonical URL.
